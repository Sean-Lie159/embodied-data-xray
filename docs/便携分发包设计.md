## 1. 目标与形态

同事拿到一个 zip 包，**解压 → 双击「启动.bat」→ 浏览器自动打开 UI → 直接提问**。
全程无需安装 Python、无需 pip、无需配置 API、无需管理员权限、无需联网装依赖。

分发包结构（打包脚本产物）：

```
EmbodiedDataAgent/                # 包根
├── runtime/                      # 内嵌 Python 3.12 + 全部依赖（约 500MB）
│   ├── python.exe
│   └── Lib/site-packages/        # streamlit/agents/pandas/... 连静态资源一起
├── app/                          # 项目代码
├── scripts/
├── streamlit_app.py
├── main.py
├── requirements.txt
├── .env                          # 预填：代理地址 + key + hy3（见第 5 节）
├── .streamlit/
│   └── credentials.toml          # 免 streamlit 首次运行 email 问卷
└── 启动.bat                      # 双击入口（ANSI 编码，见 4.3）
```

代码与环境分离：`runtime/` 几乎不变（依赖锁版本），代码更新只需重发 `app/` +
`streamlit_app.py` 等小文件覆盖（或整包重发）。

## 2. 需要 owner 先确认的三件事（打包前置）

1. **hy3 代理软件是什么**（自写 FastAPI？one-api/new-api？llama.cpp server？）——
   决定改监听的具体改法（见第 6 节分类指引）；
2. **确认把 key 随分发包分发**：key 将明文存在于包内 `.env`，包流转到内网外的
   任何人 = key 泄露。缓解：仅发给指定同事 + 定期换 key（代理侧重置）；
3. **确认代理可以常开**：同事要用时，你的电脑必须开机且代理进程活着
   （这不可回避——模型推理/转发发生在你的机器上）。

## 3. 打包脚本规格（`scripts/build_portable.py`，实施产物）

脚本行为（固定步骤，幂等）：

1. **获取内嵌解释器**：下载 python-build-standalone 的 Windows install_only 版
   （astral-sh/python-build-standalone releases，形如
   `cpython-3.12.x+2024xxxx-x86_64-pc-windows-shared_install_only.tar.gz`）。
   不用官方 embeddable 版——后者默认禁用 site-packages、pip 要 get-pip 手动装，
   坑多。下载结果缓存到本地（不重复下载）。
2. **安装依赖**：用内嵌解释器直接 `python -m pip install -r requirements.txt`
   （装进 runtime 主环境，不用 venv——install_only 版支持 venv 但主环境更少
   一层路径变化）。`pytest` 从分发包剔除（生产包不带测试框架）。
3. **预热 matplotlib 字体缓存**：跑一次 `python -c "import matplotlib"`
   并把缓存目录复制进包内 `runtime/mplcache`（见 4.2，避免同事首次启动卡顿/
   只读目录报错）。
4. **复制项目代码**：`app/`、`scripts/`、`streamlit_app.py`、`main.py`、
   `requirements.txt`（不含 `tests/`、`outputs/`、`data/`、`reference/`、
   `.env`、`.git`）。
5. **生成包内 `.env`**：预填三项（见第 5 节）。key 从**部署机现有 `.env` 读取**
   注入（脚本本身不硬编码 key，保证脚本可入库）。
6. **生成 `.streamlit/credentials.toml`**（内容 `[general]\nemail = ""`），
   防 streamlit 首次运行弹出 email 问卷。
7. **生成 `启动.bat`**（规格见 4.1）。
8. **打包 zip** 到 `dist_portable/EmbodiedDataAgent_<日期>.zip`。
   `dist_portable/` 加入 `.gitignore`。

执行方式：`python scripts/build_portable.py [--key-from .env] [--base-url ...]`，
参数缺省从部署机 `.env` 推断。

## 4. 启动器与运行时环境细节

### 4.1 `启动.bat` 逻辑

```bat
@echo off
cd /d %~dp0
set "PATH=%~dp0runtime;%~dp0runtime\Scripts;%PATH%"
set "MPLCONFIGDIR=%~dp0runtime\mplcache"
set "STREAMLIT_BROWSER_GATHER_USAGE_STATS=false"
"%~dp0runtime\python.exe" -m streamlit run streamlit_app.py --server.port 8501
```

要点：`--server.address` 不写（默认 127.0.0.1，单机自访问，**不对局域网暴露
8501**——同事用的是自己机器上的服务，不需要网络暴露）；不加 `--server.headless`
（streamlit 自动打开默认浏览器，无需 `start` 抢跑）。**bat 文件保存为 ANSI/GBK
编码**（Windows 中文系统默认代码页；UTF-8 保存的 bat 中文注释会乱码）。

### 4.2 两个已知的运行时坑（打包时消化）

- **matplotlib 字体缓存**：首次 import 会在用户主目录生成缓存，只读目录/受限
  账户会报错。方案：包内预建 `mplcache` 并设 `MPLCONFIGDIR`（4.1 已含）。
- **streamlit 首次 email 问卷**：credentials.toml 预置（3.6 已含）。

### 4.3 杀毒软件

纯 bat + 官方解释器无签名问题；若未来把启动器做成 exe 会触发误报，故**不做
exe 启动器**。

## 5. `.env` 预填规则（含 IP 策略）

```
OPENAI_API_KEY=<部署机 .env 的 key，构建时注入>
OPENAI_BASE_URL=http://<owner内网IP>:8787/v1
DEFAULT_MODEL=hy3
DEFAULT_TEMPERATURE=0.2
```

**IP 会变的对策**（二选一，构建前确定）：

- **方案 A（推荐）：路由器 DHCP 静态绑定**——把 owner 电脑的 MAC 绑定固定 IP
  （如 192.168.1.100），此后预填值永不变。一次性配置，各品牌路由器均有此功能；
- **方案 B：主机名替代 IP**——预填 `http://<电脑名>:8787/v1`（Windows NetBIOS
  名，`hostname` 命令可得），IP 变化不受影响；依赖内网 NetBIOS 解析，个别网络
  环境可能失效，用前在同事机器上 ping 一次验证。

两种都测试过再定稿。`<owner内网IP>` 占位符在构建时由脚本参数注入或手工替换
（构建在 owner 机器上运行，天然知道自己的 IP）。

## 6. 打通同事到代理链路的操作（选定：**不改代理**，portproxy 转发）

目标：让局域网同事能访问你机器 8787 端口的 hy3 代理。
**已选定方案 = 不改代理**：hy3 代理本身继续只听 127.0.0.1（零代码、零重启
风险），由 Windows 自带 portproxy 把外部进来的 8787 转发到本机回环。

### 6.1 一次性配置（部署机，管理员 PowerShell）

在**你的部署机**以管理员身份打开 PowerShell，执行一次（幂等，可重复跑）：

```powershell
# 1. 建立转发：外部任意网卡 8787 → 本机 127.0.0.1:8787（代理仍听回环不变）
netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=8787 connectaddress=127.0.0.1 connectport=8787

# 2. 放行防火墙入站 TCP 8787（专用网络）
netsh advfirewall firewall add rule name="hy3-proxy-8787" dir=in action=allow protocol=TCP localport=8787
```

验证本机已监听：`netsh interface portproxy show v4tov4`，应列出上面的规则。
**无需重启代理**——转发层对代理透明。

### 6.2 一键脚本（部署机，管理员身份双击运行）

为避免手工敲 netsh 出错与遗忘，提供 `scripts/setup_portproxy.ps1`：

```powershell
# 用法：在部署机"以管理员身份运行 PowerShell"，执行
#   powershell -ExecutionPolicy Bypass -File scripts/setup_portproxy.ps1 -Port 8787
param([int]$Port = 8787)
# 非管理员自动提权（UAC 弹窗）
if (-not ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)) {
    Start-Process powershell -Verb RunAs -ArgumentList "-ExecutionPolicy Bypass -File `"$PSCommandPath`" -Port $Port"
    exit
}
netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=$Port connectaddress=127.0.0.1 connectport=$Port
netsh advfirewall firewall add rule name="hy3-proxy-$Port" dir=in action=allow protocol=TCP localport=$Port
Write-Host "完成：外部 $Port 已转发到本机 127.0.0.1:$Port，防火墙已放行。"
netsh interface portproxy show v4tov4
```

（该脚本内容后续随 `build_portable.py` 一起提交；此处为便于你手工执行列出。）

### 6.3 跨机验证（发布前必做）

在**另一台同事电脑**上验证链路通了，再发分发包。方法：该机器浏览器开
`http://<部署机内网IP>:8787/v1/models`：
- 返回 **401/403**（"未授权"但页面有内容）＝ **端口已通**（转发+防火墙 OK，
  key 未带所以未授权，属预期）；
- 浏览器"无法访问/连接被拒"＝ 未通——检查：转发规则是否 add 成功、
  防火墙是否放行、代理是否在跑（本机 `curl http://127.0.0.1:8787/v1/models` 应
  有响应）。

### 6.4 撤销与排障

- 撤销转发：`netsh interface portproxy delete v4tov4 listenaddress=0.0.0.0 listenport=8787`
  （防火墙规则名 `hy3-proxy-8787` 如要删：`netsh advfirewall firewall delete rule name="hy3-proxy-8787"`）；
- 转发规则重启后仍生效（Windows 服务 iphlpsvc 承载，非会话级）；
- **分发包内 `.env` 的 key 属你个人额度**：`0.0.0.0` 监听意味着局域网内知道
  key 的人都可烧你额度。缓解：仅可信内网、发给指定同事、定期在代理侧重置 key；
  同事本机自带包内的 key，无需再配。

### 6.5 与分发包预填的关系

分发包 `.env` 预填 `OPENAI_BASE_URL=http://<部署机内网IP>:8787/v1` + 注入 key。
IP 建议按第 5 节做 DHCP 静态绑定（或主机名方案），确保预填值长期有效。portproxy
打通的是"同事机器 → 部署机 8787"这段网络；**同事本机的 8501 是 streamlit 服务，
只听 127.0.0.1，不需要也不应暴露到网络**（各自本地使用）。

## 7. 更新机制

- **常规更新**（代码改动）：重跑 `build_portable.py`（几分钟）发新 zip——最简单
  可靠，前期用这个；
- **轻量更新**（仅 `app/` 等小文件改动）：发一个小 zip 让同事覆盖包根对应文件
  （`runtime/` 不动）；前提是依赖无变化。
- **依赖变更**（requirements.txt 改动）：必须全量重打。

## 8. 验收清单（发包前必做）

在**无 Python 的干净环境**（另一台同事电脑或干净 VM）执行：

1. 解压 zip 到本地磁盘（**不要从网络共享盘直接运行**——site-packages 须可写，
   且杀软对网络盘扫描慢）；
2. 双击「启动.bat」→ 浏览器自动打开 UI → 引导页**不应出现**（.env 已预填，
   `is_configured()` 为 True）；
3. 直接加载示例数据集 → 对话成功（证明：内嵌解释器、依赖、代理链路全通）；
4. 让同事传一个真实小数据集 → 概况/质检/绘图正常；
5. 二次双击启动 → 无 email 问卷、matplotlib 无缓存报错。

## 9. 风险与边界

- **key 明文**：包内 `.env` 含可烧额度的 key；包仅限指定同事，泄露即换 key；
- **依赖 owner 在线**：模型代理在你的电脑上，你关机 = 全员不可用（这正是选择
  A 方案的原因——同事也可以随时改填自己的 key 走自持路线）；
- **包体**：zip 约 250–350MB，内含 numpy/pyarrow/h5py 等含 DLL 的包，缺系统
  VC++ 运行库时如报 DLL 错误，装一次 VC++ 2015-2022 redist 即可（文档随包
  附一句提示）；
- **仅 Windows x64**；同事若用 Mac 需另行打包（暂不做）；
- **首启速度**：解压后首次启动 streamlit 约数秒，属正常。

## 10. 明确不做

- 不做 PyInstaller 单 exe（streamlit 运行时资源定位坑多、杀软误报、全量重打）；
- 不做自动更新器（手动覆盖/重发即可，规模不需要）；
- 不做 Mac/Linux 分发包（同事环境均为 Windows）；
- 不把 key、内网 IP 写进任何入库文件（构建时注入，`build_portable.py` 本身
  从部署机 `.env` 读 key）。
